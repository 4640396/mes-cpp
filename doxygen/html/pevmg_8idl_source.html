35//## PosEventManager Documentation:
36// PosEventManager creates all kinds of event objects
37// and manages them in a queue of event objects.
38
39// PPTManager will invoke create methods for event
40// object
41// and will invoke set methods of event object.
42// Created event object will be inserted at the last
43// of a queue of PosEventManager.
44
45// HistoryWatchDog program will get the first event
46// object in FIFO order and the event will be
47// reflected to several history tables. Similarly
48// CFMWatchDog program will get the first event
49// object in FIFO order and the event will be sent to
50// CFMManager as CFM send records.
51// If the event is reflected by both WatchDog
52// programs, the event object will be deleted and
53// removed from the queue of PosEventManager.
